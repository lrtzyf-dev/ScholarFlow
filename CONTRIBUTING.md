# Contributing

Thanks for considering a contribution.

1. Open an issue to describe a substantial change before starting work.
2. Keep changes focused and avoid including user papers, database files, API credentials, or generated installers.
3. Run the relevant backend tests and frontend typecheck/build before opening a pull request.
4. Describe user-visible behavior, test coverage, and any data-handling changes.
5. New source contributions are submitted under the repository license (see LICENSE: source-available, prior written permission required for use and derivative work).

Third-party code and assets must retain their original license and attribution.
