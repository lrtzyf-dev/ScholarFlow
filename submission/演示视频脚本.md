# 研序 ScholarFlow 演示视频脚本（约 7 分钟）

目标格式：普通话讲解，建议同步录制字幕；MP4，1920×1080 或更高，时长控制在 5–8 分钟。录制 Windows 桌面 EXE，避免把浏览器开发工具或测试日志作为主画面。

## 0:00–0:40 项目介绍

旁白：研序 ScholarFlow 是面向科研阅读的 Windows 桌面 Agent。它把 PDF 解析、混合检索、引用溯源问答、原文定位和项目协作工作流放在同一条链路中。没有 API Key 时也能用离线 Mock 模式完成演示，配置兼容 OpenAI 的模型后可以切换真实模型。

## 0:40–2:00 导入与解析 PDF

操作：启动 EXE，进入文献库，加载示例论文或上传一份 PDF。

旁白：系统保留论文、页码、段落和版式坐标。解析完成后打开版式阅读，展示原文页面、页码和证据高亮。这里强调阅读视图与问答引用共用同一份文献证据。

## 2:00–3:20 检索与引用溯源问答

操作：在抗幻觉问答输入一个需要跨段落核对的问题，展示流式思考、检索过程和最终答案；点击答案中的引用编号。

旁白：检索同时使用关键词和向量相关度，再用 RRF 合并排序。Agent 先取得证据，再组织答案；引用闸门逐句检查是否有证据支持。点击引用会跳转到对应论文、页码和原文位置。没有证据时系统明确拒答，避免把模型记忆伪装成论文结论。

## 3:20–4:30 项目文件、Git 与工作树

操作：在侧栏添加一个项目，打开项目文件和版本控制页，展示差异、暂存、提交记录；再展示工作树创建与同提交改动迁移的审阅界面。

旁白：项目上下文按文件快照注入任务。Git 写操作先生成可审阅提案，提交只包含已暂存内容。工作树迁移会核对 HEAD、目标干净状态和活动任务，备份后再搬运字节与暂存状态，发生中断时可继续或撤回。

## 4:30–5:30 计划模式、任务恢复与终端

操作：切换到计划模式，生成计划并审阅；打开任务页和项目终端，展示恢复入口。

旁白：计划模式只开放读取类工具，审阅后才能执行。后台任务持久化检查点，程序重启后可选择继续或从头重新运行。终端使用 Windows PowerShell 或 cmd，并以独立辅助进程承载交互输出。

## 5:30–6:30 AI 技术亮点

旁白：模型层采用 OpenAI 兼容协议，便于接入百炼、硅基流动、DeepSeek 或本地 vLLM。离线模式使用确定性向量和脚本模型保证可复现；在线模式支持流式输出、工具调用和推理强度配置。证据对象带有来源、页码、段落和坐标，答案经过引用校验；长会话采用增量压缩但保留原始记录。所有密钥只保存在本地配置或环境变量中。

## 6:30–7:00 总结

旁白：研序 ScholarFlow 已形成从文献进入、证据检索、可追溯回答到项目执行的 Windows 桌面闭环。当前版本的测试与限制均在技术文档中公开记录，后续将补齐公网部署、录制正式视频，并继续根据对标证据优化桌面交互。
