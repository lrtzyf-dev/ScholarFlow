# 在线演示说明

## 当前状态

本版本已经完成 Windows 桌面端离线可运行演示，但尚未配置公网服务器、域名、容器平台或评审账号。因此当前不能提供真实在线演示 URL，也不使用 `localhost` 或 `127.0.0.1` 作为公网地址。

## 待部署信息

在取得服务器或部署平台后，按下面字段补齐并提交：

| 字段 | 内容 |
| --- | --- |
| 在线演示地址 | 待部署 |
| 访问协议 | HTTPS |
| 评审账号 | 待创建；不使用个人账号 |
| 评审密码 | 通过大赛官网或安全渠道单独提供 |
| 服务有效期 | 覆盖评审窗口 |
| 健康检查 | `GET /api/health` 返回 `status=ok` |

## 本地演示替代方案

评审未取得公网地址前，可在 Windows 上直接运行 `ScholarFlow.exe`。不配置 API Key 时，应用使用 Mock LLM 和本地确定性向量，PDF 导入、检索、引用溯源问答和桌面工作流均可离线演示；真实模型需要在应用设置页或环境变量中配置。
