# Windows 桌面：模型 Git 闭环

范围为 1440×900 和 1100×700，手机端不在本次范围内。最终产物位于 `desktop/ScholarFlow/ScholarFlow.exe`，独立验收包为 `研序ScholarFlow-桌面验收版-20261031-模型Git闭环.zip`。

## 用户可见变化

- 模型可在绑定项目的聊天中请求暂存、取消暂存或提交已暂存内容。审批卡直接显示操作、分支、文件范围与提交说明，打开“查看 Git 审阅”可核对完整差异。
- 聊天历史与后台任务保留操作入口；打开的待确认/执行中审阅自动更新，已结束操作可手动刷新。模型操作在项目的版本控制历史中也可查看，但仍须通过所属任务审批。
- 拒绝不写入索引，工作文件和索引发生外部变化时旧审阅失效；已完成提交的结果丢失后从持久记录恢复，不重复提交。审批中停止或重启会取消旧提案。
- 中文文件名在差异中直接显示，不再用八进制转义码表示。
- 额外修复子任务只读约束：执行前检查工具名，即使模型返回未开放写入工具也不会派发。

## 当前边界

需要本机安装 Git，单次最多 1,000 路径、256 KiB 差异、暂存单文件 2 MB。提交尊重本机 hooks 和签名配置，外部 Git 并发不能完全隔离。任务停止不强制杀死正在写入的 Git，仍按进程超时/应用退出机制收尾；中断结果需核对。

尚缺远程同步、创建/管理工作树、特殊合并/变基/子模块流程。模型质量用受控响应替代，未验证外部真实模型选择提交范围的正确性。

Computer Use 原生管道本轮仍不可用，未取得本机 Codex 基准截图；原生窗口输入法、系统剪贴板、正常关闭和像素级一致性均未验证。具体剩余差距见根目录 `差距审计.md`。
