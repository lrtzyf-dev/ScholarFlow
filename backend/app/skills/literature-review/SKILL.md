# 文献综述技能

## 何时使用
用户要"写文献综述 / 研究现状 / related work / 梳理领域脉络 / 找研究空白 / 开题报告的国内外研究现状"。

## 工作流程
1. **界定范围**：明确主题、时间跨度、学科边界与综述目的（背景型 / 对比型 / 论证型）。
2. **系统检索**：用 paper-search 技能覆盖 arXiv / Semantic Scholar / Crossref，找奠基性工作与最新进展。
3. **分类组织**：按"方法流派 / 技术路线 / 应用场景 / 时间阶段"归类，而非逐篇罗列。
4. **对比综合**：用表格或分组对比各流派的思路、数据、优势、局限。
5. **提炼空白**：指出尚未解决的问题、矛盾结论、被忽视的方向（即研究机会）。

## 写作结构（可按需求裁剪）
- 引言：综述范围、意义与组织方式。
- 主体：按主题/流派分节，每节讲"代表工作 → 做法 → 优劣"。
- 对比与脉络：横向对比表 + 纵向演进（可配图）。
- 研究空白与展望：现有不足、未来方向。
- 参考文献：规范引用（见 citation-format 技能）。

## 注意
- 综述是"综合"不是"摘要堆砌"：每段要有论点，论文是支撑论点的证据。
- 论断要可溯源：引用具体论文，区分"已证实的共识"与"尚有争议"。
- 优先引用高影响力奠基工作与近 2–3 年的代表性进展。
