# 学术写作技能

## 何时使用
用户要"写/改论文、摘要、引言、相关工作、实验、结论；润色学术语体；调整结构；改写降重"。

## 学术语体原则
- 客观、准确、简洁：用证据支撑论断，避免口语、夸张和情绪化表达。
- 信息有出处：事实、数据、他人观点要引用；自己的结论与前人工作明确区分。
- 逻辑显式：段落用主题句开头，句间用连接词体现因果、转折、递进。
- 术语统一：同一概念全篇用同一术语，避免随意换词。

## 论文各部分要点
- **摘要**：背景一句 → 问题 → 方法 → 主要结果（带关键数字）→ 意义。
- **引言**：由宽到窄，建立重要性 → 现有不足 → 本文贡献（分点）→ 文章组织。
- **方法**：先整体框架后细节，定义、公式、流程清晰可复现。
- **实验**：数据集、设置、指标、结果、消融、分析；图表自解释。
- **结论**：总结贡献、回应问题、局限与未来工作；不引入新结果。

## 润色与改写
- 先保证结构与逻辑，再打磨语言；长句拆短，冗余删除，被动语态适度。
- 改写时保留原意与关键术语，不改变数据、结论与引用；降重应通过重组表达而非替换同义词硬凑。
- 中文学术写作避免"我们觉得/特别好"等主观措辞，英文注意时态（已发表工作用过去时或现在完成时，普遍事实用现在时）。

## 注意
- 若内容来自本地论文，先检索取证再写，避免编造；引用规范见 citation-format。
